
# Identidade Visual — Cityzer

## Conceito

A Cityzer utiliza uma identidade visual inspirada na mobilidade urbana, na tecnologia e na cidade de São Paulo.

## Paleta

- Fundo: #071119
- Superfície: #10252B
- Verde principal: #50E8B0
- Ciano secundário: #16C6CC
- Texto principal: #F3F7F8
- Texto secundário: #B9CBD0

## Tipografia

Segoe UI, com fontes de sistema como alternativas.

## Site de apresentação

- Fotografia real da Ponte Estaiada ao fundo.
- Logo no canto superior esquerdo.
- Celular centralizado.
- Card explicativo à esquerda.
- Nenhum menu de navegação externo.

## Aplicativo

- Interface escura.
- Elementos interativos em verde e ciano.
- Ícones específicos para cada ocorrência.
- Navegação dentro da moldura do celular.
- Interface adaptada ao espaço disponível.

## Princípios

- Clareza visual.
- Alto contraste.
- Acessibilidade.
- Consistência.
- Responsividade.
- Animações moderadas, sem prejudicar a utilização.
